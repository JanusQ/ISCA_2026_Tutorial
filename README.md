# Janus 4.0: Quantum-classical Heterogeneous Architecture and Flexible Scheduling (Tutorial at ISCA 2026)

This repository contains the webpage for the Janus 4.0 tutorial at ISCA 2026. The tutorial will take place on Sunday, June 28, 2026 during the morning session, 8:00am-12:00pm EDT, in Room 305B at the Raleigh Convention Center.

Janus 4.0 focuses on quantum-classical heterogeneous architecture and flexible scheduling. The tutorial covers the Janus quantum cloud platform, Qtenon for low-latency hybrid quantum-classical architecture integration, ARTERY for fast quantum feedback using branch prediction, AdaptDQC for adaptive distributed quantum computing, Choco-Q for constrained binary optimization, and EXP-QRAM for bucket-brigade quantum random access memory on superconducting devices.
